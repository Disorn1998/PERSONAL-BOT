# HTTP พื้นฐาน

HTTP เป็นโปรโตคอลสำหรับแลกเปลี่ยนเอกสารบนเว็บ ระหว่างไคลเอนต์ (เบราว์เซอร์) กับเซิร์ฟเวอร์

## เมธอดที่ใช้บ่อย
- **GET** ดึงข้อมูล ไม่ควรมีผลข้างเคียง
- **POST** ส่งข้อมูลเพื่อสร้างหรือประมวลผล
- **PUT** แทนที่ทรัพยากรทั้งก้อน
- **DELETE** ลบทรัพยากร

## สถานะโค้ด
- 2xx สำเร็จ เช่น 200 OK
- 4xx ข้อผิดพลาดฝั่งไคลเอนต์ เช่น 404 Not Found
- 5xx ข้อผิดพลาดฝั่งเซิร์ฟเวอร์ เช่น 500 Internal Server Error

## Headers ที่เกี่ยวข้อง
- `Content-Type` บอกชนิดข้อมูลในบอดี้
- `Authorization` ส่งโทเคนหรือคีย์สำหรับยืนยันตัวตน
